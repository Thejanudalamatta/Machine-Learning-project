## **Machine Learning Project**

This project was done as part of a university project and explores three real-world datasets using both unsupervised and supervised learning techniques.
The goal was to formulate research questions, build predictive models, compare algorithm performance, and situate findings.

### **Datasets**

Three datasets were obtained from kaggle 
Each dataset covers domains that are different and diverse to eachother
Preprocessing apples: Cleaning, handling missing values/null values, etc, feature engineering and more

### **Techniques**

**Unsupervised learning**:

Clustering (K-means)

Dimensionality reduction (PCA)

**Supervised learning**:

Regression

Classification


### **Research Objectives**

1) Formulate research questions that are specific to each domain
2) Apply unsupervised and supervised techniques, and build predictive models
3) Compare model performance using applicable evaluation metrics
4) Situate findings with existing literature
